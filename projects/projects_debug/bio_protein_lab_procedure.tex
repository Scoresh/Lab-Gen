\section{Abstract}\label{abstract}

To show the denaturing of amylase through the change in pH levels and how the efficacy and efficiency of enzyme performance are scale-based.

\section{Background / Introduction}\label{background-introduction}

\section{Question / Problem}\label{question-problem}

How does \textbf{\emph{amylase}}, an enzyme found in saliva, break polysaccharides into simpler carbohydrates in different PH levels?

\section{Elements \& Hypothesis}\label{elements-hypothesis}

\subsection{Hypothesis}\label{hypothesis}

If the pH levels of three solutions of pH \{4, 5.5, 7\}, are exposed to the enzyme \emph{amylase} found in saliva and mixed with a polysaccharide containing cracker, then there should be a trend whereas the pH 7 solution will have the highest density of glucose, the pH 5.5 solution should have the medium density of glucose, and the pH 4 solution should have the lowest density of glucose.

\subsection{Experimental Elements}\label{experimental-elements}

\begin{itemize}
\tightlist
\item
  Independent Variable: PH Level of the solution
\item
  Dependent Variable: Glucose concentration produced (in mmol/L)
\item
  Experimental Groups:

  \begin{itemize}
  \tightlist
  \item
    Group 1: Saltine Cracker, Saliva, pH 4.0 solution
  \item
    Group 2: Saltine Cracker, Saliva, pH 5.5 solution
  \end{itemize}
\item
  Positive Control Group:

  \begin{itemize}
  \tightlist
  \item
    Saltine Cracker, Saliva, optimal pH solution (pH 7.0)
  \end{itemize}
\item
  Negative Control Group:

  \begin{itemize}
  \tightlist
  \item
    Saltine Cracker, optimal pH solution (pH 7.0)
  \end{itemize}
\item
  Controls

  \begin{itemize}
  \tightlist
  \item
    Saliva to Solution ratio
  \item
    Cracker to Solution ratio
  \item
    Time allowed for enzymatic processes
  \item
    Method of glucose measurement
  \end{itemize}
\end{itemize}

\subsection{Set Up Procedure}\label{set-up-procedure}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  All lab materials were collected and thoroughly inspected to ensure cleanliness.
\item
  Two sets of four test tubes were labeled with \{"C","pH=7","pH=5.5","pH=4"\} using tape and a marker.
\item
  The first set of four test tubes were filled with 10 mL of distilled water.

  \begin{itemize}
  \tightlist
  \item
    The water was filled up in the first beaker with about 100 mL of distilled water.
  \item
    The vinegar was filled up to about the 50 mL mark of the second beaker.
  \end{itemize}
\item
  Then, according to the test tube labels, the first set of four had 2 mL of vinegar added incrementally (until the pH was correct) and checked via a pH strip.
\item
  When all four test tubes of the first set were at the pH level indicated by each respective label, the tubes were put away, in a row, back onto the test tube rack
\end{enumerate}
